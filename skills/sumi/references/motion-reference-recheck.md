## Implementation consequences

The guides deliberately distinguish observed behavior from proposed code implementations. A particular reference may need several original poses, intermediate drawings, depth layers, alpha masks or actual geometry; one generated still cannot provide arbitrary turns, believable combat or full performance. These routes remain possible with images and browser-rendered code, but the production effort must match the action.

Similar materials justify a family, not erasure of differences. Print retains environment, intimate acting and action subcases; Grain retains sculpted graphic and gestural/festival subcases. Select or combine them for the prompt. If a future reference demonstrates a genuinely different motion system, extend the guide or create a variation rather than force it into a palette category.

For a new film, select the relevant reference passage, inspect its timing and causal motion more closely if needed, then author an original hardest-shot proof. The current documentation is a researched direction, not evidence that a future film matches its references or is free of defects.

# Images first; SVG by choice or fallback

Inspect actual callable built-in image generation, connected image MCP/API and supplied artwork. A host/model name is not a generation capability. Report unknown honestly; metadata checks must not spend credits.

Ask which exposed image tool/model to use when not already selected. Reuse its saved non-secret identifier after checking it is available. Disclose known costs before paid generation. Do not install a local model or collect a key in chat merely to probe images.

SVG is the explicit vector choice or an offered fallback when image generation is unavailable. Say that it can look attractive but usually has simpler painted detail and complex pose fidelity than suitable generated art. Offer connecting an image tool, using supplied art or another capable host. Do not silently downgrade a requested painted film.

The optional first-use comparison is **one image, one shared scene, three styles**. A requested comparison can double as the tool proof; do not make another redundant sample. Use the chosen route and preserve the same character/action/composition enough to compare treatment. Any separate panels/labels belong to this teaching image, not the exported movie. If no sample is requested, proceed to the project's own art proof.

For SVG load the suite's `sumi-svg` companion and only the selected SVG style guide. A full action batch follows inspection of a complete contextual proof. All art routes keep scene-first layout, complete poses, camera/acting/environment, captions and physical review. No new fourth style is introduced.

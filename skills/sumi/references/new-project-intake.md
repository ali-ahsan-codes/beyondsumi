# Default flow for a new story

Read saved preferences and the latest brief; the current request wins. Recheck relevant tool availability, not every installed tool on every prompt. Ask only missing story/audience/feeling/language/runtime/aspect/must-keep details. Briefly recommend a style with a reason and name all three; an explicit choice needs no repeat question. Images remain preferred; SVG requires selection or an explained unavailable-image fallback.

Reuse the saved narration/sound routes. For saved supplied narration ask **Narration for this film, or music/effects only?** Request the complete recording if wanted. For dialogue, collect speaker→file/segment→exact line→desired delivery; the user may name files such as `king_01.wav`, but renaming is not required. Use timestamps for combined files. Preserve supplied files and meanings; reconcile words/timing with actual audio/transcription capability. Explain unavailable understanding rather than pretending to hear.

If duration or telling mode is missing, ask duration first, then narrator, character dialogue or both. Offer help writing/refining the story before film production. Follow [story writing](story-writing.md) for hook, emotional delivery, causal engagement and script review. If the story is unwritten help write it. Present the script first; after review, direct complete scenes and camera before generating artwork. Use the [director workflow](director-workflow.md) and [duration contract](script-duration.md). Show the full estimate versus a concrete short alternative when needed, selected edition, art/voice/sound route and any costs. Respect exact existing approval; do not re-ask each shot.

After approval, measure actual speech and plan dialogue using [casting/lip-sync](dialogue-and-lip-sync.md). Establish complete contextual masters and whole action phases, then animate, score and review. Sound-only films retain concise approved-story captions unless explicitly text-free. Never pad to a nominal runtime or repeat an action to fill space.

Use `VOICE-MAP.json` for roles/audio when applicable; keep unneeded voice setup inactive. Retain separate original sources, editable stems, event ledger and concise project memory. Only the requested edition is produced; the dashboard offers the others as requests.

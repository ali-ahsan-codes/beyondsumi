What you need

The app is a set of local files, not an installer. Download or copy the project folder first; after that, you can disconnect from the internet.

A current desktop browser

Firefox, Chrome, or Edge. A current browser is recommended for Canvas playback and WebM recording.

Python 3

Used only to serve the local files so sample JSON can load. Python's standard library is enough; there are no Python packages to install.

Your own media (optional)

Voice recordings, music, sound effects, and reference art can be uploaded. Use only material you own or are allowed to use.

No AI account or API key

The Studio does not call an LLM, image generator, cloud service, or API. It has no npm install step.

Install and launch

  1. Download the project. Get a ZIP/release or copy the repository folder onto the computer where you will create stories. Extract it. Keep the folder together so the sample projects remain available.
  2. Open a terminal in the studio folder. In File Explorer/Finder, open the project's studio folder. Open Terminal or Command Prompt there. You can also type cd path/to/project/studio in a terminal, replacing the example with your folder's actual path.
  3. Start the local file server. On Windows run py -m http.server 8765 --bind 127.0.0.1. On macOS/Linux run python3 -m http.server 8765 --bind 127.0.0.1. If py is not recognised, try python -m http.server 8765 --bind 127.0.0.1.
  4. Open the app. In the same computer's browser, visit http://127.0.0.1:8765. The Studio page should appear. Leave the terminal open while working; return to it and press Ctrl+C to stop the server when finished.
Important: Run the server from inside studio/, not from the repository root, and do not open index.html as a file:// URL. This app loads sample projects with local browser fetches. The loopback address keeps the server on your computer; do not expose it to a public network.

Everyday workflow

You can create and edit a story entirely through the Studio's buttons and form controls. JSON is optional: import it when you want to start from a prepared project or template.

  1. Choose a starting point. Open one of the four samples from Samples, click New project for a blank story, or use Import project to load a compatible JSON file.
  2. Write the story. In Story, set the title, logline, genre, audience, target length, visual style/palette, story text, and character descriptions. Give characters clear, repeatable visual descriptions.
  3. Direct each shot. In Direction, set the location, action, shot duration, camera angle/framing, transition, narration, dialogue and sound notes. Use Add scene to create shots, then the scene controls to reorder or remove them. Keep directions short and make each shot move the story forward.
  4. Add voice, sound, and art if wanted. In Sound & voice, upload narration/music and add sound effects at the relevant scene/time. In Assets, add reference images and choose whether they appear in the scene. Uploaded media stays in the browser session until you export a project JSON.
  5. Preview and review. Play or scrub the timeline; inspect every shot and check story continuity, character actions, camera, timing, captions, audio levels, and rights to uploaded media. The animation is a procedural 2D animatic preview, not a finished hand-drawn film.
  6. Save a backup before closing. Click Export project JSON and keep the downloaded file somewhere safe. Browser autosave remembers story/settings but does not preserve uploaded media; the exported project JSON can embed that media.

Save and export

Project JSON

Editable project backup. Import it later with Import project. Uploaded media is embedded for portability, within the app's size limits.

PNG frame

Use Save frame to download the currently displayed frame as an image.

WebM video

Use Export video to record the animation in a browser-supported WebM format. Browser and audio support vary; test a short export first.

Narration preview

A speech voice supplied by your operating system/browser may be available for preview. It is not a saved voice track; upload your own recording for predictable narration and an exportable voice track.

For dependable backups, export the JSON after important edits and keep a second copy outside the project directory. Do not rely on browser autosave for uploaded audio or images.

Samples and reusable template

The four editable sample projects are The Lantern Keeper, The Last Seed, The Moon Ferry, and The Brave Little Cloud. They demonstrate story structure, characters, multiple camera angles, scene actions, timings, transitions, dialogue/narration, and sound cues. Open them from the Studio's Samples menu.

For a new story, use Download blank story template in the Studio, fill it in through the UI or edit its JSON in a text editor, then import it. Field names, examples, and validation details are in the Story JSON format reference.

A complete video may also need final narration, music, sound effects, captions, approved artwork, credits, an opening/title card, and an end card. Check the story's rights and review the exported video in a media player/editor before publishing. Exporting a project does not grant rights to any imported material.

Offline use and limitations

  • Download the project and browser before going offline. Once files are on disk, the Studio makes no network requests and has no AI/LLM runtime dependency.
  • Python only serves local files; it does not install packages, create accounts, or send your projects anywhere.
  • The app creates a lightweight procedural 2D story animatic. It is not a full hand-drawn animation suite, AI image/video generator, voice cloning system, or professional nonlinear editor.
  • WebM video and audio recording depend on browser support. Uploaded narration/music are best for dependable results; system speech preview availability varies.
  • Uploaded media is not part of browser autosave. Export the project JSON to retain it. The app has per-file/project size limits shown in the interface.

Troubleshooting

The samples do not appear

Confirm the server was started from studio/ and open the local http://127.0.0.1:8765 address, not a file:// page.

The browser says the page is unavailable

Keep the terminal server running. If port 8765 is busy, start with 8766 and open http://127.0.0.1:8766.

I cannot hear speech

Device speech preview depends on browser/OS voices. Upload a narration recording if you need predictable playback and export.

Video export is missing or fails

Try an up-to-date desktop Firefox, Chrome, or Edge. First test a short story; project JSON and PNG frame downloads do not require video recording.

My uploaded files disappeared

Browser autosave does not retain media. Import your last exported project JSON or upload the files again, then export a fresh JSON backup.

I want to validate code changes

From the repository root, run node --test studio/test-*.mjs. Python toolkit checks use python -m unittest discover -s tests.
